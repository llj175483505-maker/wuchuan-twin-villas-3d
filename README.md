# 吴川双楼庭院 · B方案

独立于原庭院方案的三维概念网站。沿用原图1130㎡不规则地界，以55m北侧东西投影校准，场景单位为米。

- 两栋新建住宅，各12×15m外包络占地180㎡，包含凹入式门廊和阳台。默认三层，可同步切换一／二／三层。
- 两栋正门和阳台统一朝西（世界-x方向）。一号楼中心(-2.3,14)、二号楼中心(14.8,7.5)，前后错开6.5m；每栋仍为面宽12m、进深15m，占地180㎡。
- 浅色外墙、深色窗框、双层阳台、宽檐低坡屋顶，参考用户提供的住宅外观。
- 北侧出入口、西北侧三车位与6m倒车通道、两栋南侧共享花园，2m高围墙。
- 鼠标旋转、缩放、平移；手机底部设置面板、横滑视角栏与双指手势。
- 加载进度、日光／雨景／傍晚灯光、俯视尺寸、原建筑轮廓与一楼空间示意。

## 查看

静态网页，无需依赖安装或构建。运行 `python -m http.server 8770`，访问 `http://localhost:8770/`。
GitHub Pages使用main分支根目录，需保留.nojekyll。全部运行资源在仓库内，无第三方CDN或API密钥。
